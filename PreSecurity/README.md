# Pre Security

## Description

The **Pre Security** learning path builds the foundation for my cybersecurity journey. It covers the essential concepts needed before diving into advanced security topics, including computer fundamentals, networking, web technologies, operating systems, and basic programming.

Through hands-on labs and practical exercises, this path helped me understand how modern systems work, how they communicate, and how attackers exploit weaknesses. Building this foundation is an important step toward becoming a skilled cybersecurity professional.

## Learning Objectives

- Understand computer fundamentals and operating systems.
- Learn networking concepts and internet communication.
- Explore how websites and web technologies work.
- Gain basic programming knowledge.
- Develop the mindset required for both offensive and defensive security.

## Skills Covered

- Computer Fundamentals
- Networking Basics
- Linux & Windows Basics
- Web Fundamentals
- Basic Programming
- Cybersecurity Fundamentals

# Become a Hacker

## Overview

This room introduces the mindset, skills, and fundamental concepts involved in becoming an **ethical hacker**.

It explores how hackers approach problems, identify weaknesses, and develop the technical knowledge required to understand and test computer systems securely and responsibly.

## Objectives

* Understand what ethical hacking means.
* Learn how hackers approach systems and security problems.
* Understand the importance of developing a hacker mindset.
* Explore common areas of cybersecurity and ethical hacking.
* Learn the importance of continuous learning and practical experience.
* Understand the legal and ethical responsibilities of security testing.

## Skills Learned

* Ethical hacking fundamentals
* Hacker mindset
* Problem-solving concepts
* Security awareness
* Basic vulnerability concepts
* Cybersecurity learning methodology
* Analytical thinking
* Responsible security testing

## Tools Used

* TryHackMe Learning Platform
* Web Browser

## Key Takeaways

* Ethical hackers use security knowledge to identify and help fix vulnerabilities.
* A hacker mindset involves curiosity, problem-solving, persistence, and understanding how systems work.
* Learning networking, operating systems, web technologies, and security fundamentals provides a strong foundation for ethical hacking.
* Vulnerabilities are weaknesses that may be discovered and exploited in systems or applications.
* Understanding how attackers think can help security professionals build stronger defenses.
* Practical labs and controlled environments provide a safe way to develop cybersecurity skills.
* Security testing should only be performed on systems where proper authorization has been given.
* Ethical hacking requires continuous learning because technologies, vulnerabilities, and attack techniques constantly evolve.
* Building strong fundamentals is important before moving into more advanced penetration testing and offensive security topics.

## Reflection

This room helped me understand what it means to think and learn like an ethical hacker.

These concepts provide a strong foundation for continuing my cybersecurity journey and developing practical skills in ethical hacking, penetration testing, and offensive security.

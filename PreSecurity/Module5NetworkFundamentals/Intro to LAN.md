# Intro to LAN

## Overview

This room introduces the fundamentals of Local Area Networks (LANs) and explains how devices communicate within a small geographical area. It covers basic LAN concepts, network components, addressing, and how devices connect and exchange data inside a local network.

The room provides a practical introduction to LAN environments, helping build a foundation for understanding network architecture, troubleshooting, and cybersecurity concepts related to internal networks.

## Objectives

* Understand the basics of Local Area Networks (LANs).
* Learn how devices communicate within a local network.
* Understand the role of network devices such as switches and routers.
* Explore basic LAN addressing and communication methods.
* Build foundational knowledge for network security.

## Skills Learned

* LAN fundamentals
* Understanding network topologies
* Basic network device concepts
* Local network communication
* IP addressing basics
* Introduction to internal network security

## Key Takeaways

* LANs connect devices within a limited geographic area, such as homes, schools, and businesses.
* Switches are used to connect devices and forward data inside a local network.
* IP addresses and MAC addresses help identify devices and enable communication.
* Understanding LAN structures is essential for network troubleshooting and cybersecurity analysis.
* Internal networks are a common target area in security assessments, making LAN knowledge important for cybersecurity professionals.

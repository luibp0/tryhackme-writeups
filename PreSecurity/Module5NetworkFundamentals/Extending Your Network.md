# Extending Your Network

## Overview

This room introduces the concepts and technologies used to extend and manage networks beyond a basic local network.

It covers important networking components and concepts such as **port forwarding, firewalls, VPNs, routers, and switches**, explaining how they help devices communicate securely across different networks.

## Objectives

* Understand how networks can be extended beyond a local network.
* Learn the purpose of port forwarding.
* Understand the role of firewalls in network security.
* Learn the fundamentals of VPN technology.
* Understand how routers and switches handle network traffic.
* Build a stronger understanding of practical network infrastructure.

## Skills Learned

* VPN fundamentals
* Router functionality
* Switch functionality
* Network traffic management
* Basic network security concepts

## Key Takeaways

* Port forwarding allows external traffic to reach specific devices or services inside a private network.
* Firewalls control incoming and outgoing network traffic based on defined security rules.
* Stateful firewalls track active connections, while stateless firewalls evaluate packets individually.
* VPNs create secure connections that allow devices to communicate across networks.
* Routers connect different networks and determine where traffic should be sent.
* Switches connect devices within a network and forward traffic using MAC addresses.
* Understanding these technologies is important for both network administration and cybersecurity.

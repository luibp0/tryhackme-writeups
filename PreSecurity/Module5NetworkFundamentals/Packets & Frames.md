# Packets & Frames

## Overview

This room introduces the fundamentals of **packets and frames** and explains how data is structured and transmitted across networks.

It covers the differences between packets and frames, how protocols such as **TCP and UDP** transport data, and how ports are used to identify different network services and applications.

## Objectives

* Understand the difference between packets and frames.
* Learn how data is transmitted across a network.
* Understand the basic structure of network packets.
* Learn the fundamentals of TCP and UDP.
* Understand how ports are used in network communication.

## Key Takeaways

* Packets are units of data used to transfer information across networks.
* Frames operate at the Data Link Layer and contain information such as source and destination MAC addresses.
* Packets are associated with the Network Layer and contain information such as source and destination IP addresses.
* TCP provides reliable and connection-oriented communication.
* UDP provides faster, connectionless communication without guaranteeing delivery.
* Ports allow devices to identify which application or service should receive network traffic.
* Understanding packets and frames is important for analyzing network traffic and building strong cybersecurity fundamentals.

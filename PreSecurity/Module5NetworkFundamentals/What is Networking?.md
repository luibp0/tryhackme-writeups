# What is Networking?

## Overview

This room introduces the fundamentals of computer networking and explains how devices communicate and exchange data over networks. It covers basic networking concepts, including how devices connect, how information is transmitted, and the role of networking protocols.

The room provides a practical introduction to networking concepts, helping build a strong foundation for understanding communication between systems, network security, and cybersecurity operations.

## Objectives

* Understand the basics of computer networks.
* Learn how devices communicate with each other.
* Understand the purpose of networking protocols.
* Explore how data is transferred across networks.
* Build foundational knowledge for cybersecurity and network analysis.

## Skills Learned

* Networking fundamentals
* Understanding network communication
* Basic networking terminology
* Network protocols concepts
* Data transmission basics
* Introduction to network security concepts

## Tools Used

* TryHackMe Learning Platform
* Web Browser
* Network Simulation Tools

## Key Takeaways

* Computer networks allow devices to communicate and share information.
* Networking relies on protocols that define how data is transmitted and received.
* Understanding network fundamentals is essential for cybersecurity professionals.
* Devices use different addressing methods and protocols to communicate effectively.
* Strong networking knowledge helps in analyzing, securing, and troubleshooting networks.

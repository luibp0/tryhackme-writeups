# Module 1: Introduction to Cyber Security

## Overview

This module provides an introduction to the field of cybersecurity and builds a foundation for understanding how security professionals protect systems, identify vulnerabilities, and respond to cyber threats.

The module covers the basics of cybersecurity, different security roles, and the importance of both offensive and defensive security approaches.

## Key Takeaways

- Cybersecurity focuses on protecting systems, networks, and data from cyber threats.
- Offensive security helps identify vulnerabilities before attackers can exploit them.
- Defensive security focuses on detecting, preventing, and responding to attacks.
- Understanding both attack and defense perspectives is important for becoming a skilled security professional.
- Cybersecurity offers many different career paths depending on interests and skills.

# Data Representation

## Overview

This room introduces the fundamentals of how computers represent and process data. It explains how different types of information, such as numbers, text, and images, are stored and interpreted by computer systems.

The room covers essential concepts including binary, hexadecimal, data encoding, and how computers use different formats to represent information.

## Objectives

- Understand how computers represent data.
- Learn the basics of binary and hexadecimal systems.
- Explore how numbers and text are stored digitally.
- Understand different data formats and encodings.
- Build a foundation in computer fundamentals.

## Skills Learned

- Binary number system fundamentals
- Hexadecimal representation
- Data encoding concepts
- Understanding character representation
- Digital data storage concepts

## Tools Used

- TryHackMe Learning Platform
- Web Browser

## Key Takeaways

- Computers use binary values (0s and 1s) as the foundation for storing and processing data.
- Different number systems, such as decimal, binary, and hexadecimal, are used to represent information.
- Text, images, and other data types are converted into digital formats that computers can understand.
- Understanding data representation helps in areas such as programming, networking, and cybersecurity.
- Knowledge of how data is stored is important for analyzing systems and understanding how information is processed.

This room improved my understanding of how computers represent and handle data internally. Learning about binary, hexadecimal, and data encoding provides a strong foundation for understanding computer systems and cybersecurity concepts.

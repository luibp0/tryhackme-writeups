# Database SQL Basics

## Overview

This room introduces the fundamentals of databases and SQL (Structured Query Language). It covers how data is stored, organized, and managed inside databases, along with the basic concepts of querying and interacting with database systems.

The room provides a practical introduction to SQL commands and database operations, helping build a foundation for understanding web applications, data management, and cybersecurity concepts such as database security and SQL injection.

## Objectives

* Understand the basics of databases and SQL.
* Learn how data is stored and organized in tables.
* Understand how to retrieve and manipulate data using SQL queries.
* Learn the purpose of common SQL commands.
* Build confidence in reading and writing basic SQL statements.

## Skills Learned

* Database fundamentals
* SQL syntax basics
* Understanding tables, rows, and columns
* Data retrieval using SQL queries
* Data manipulation operations
* Basic database security concepts

## Tools Used

* TryHackMe Learning Platform
* SQL Database Environment
* Web Browser
* SQL Query Interface

## Key Takeaways

* Databases are used to store, organize, and manage large amounts of information.
* SQL is a language used to communicate with relational databases.
* Tables consist of rows and columns that represent structured data.
* SQL queries allow users and applications to retrieve and modify information.
* Understanding SQL fundamentals is important for cybersecurity areas such as web security, vulnerability assessment, and SQL injection prevention.

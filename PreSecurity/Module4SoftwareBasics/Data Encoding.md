# Data Encoding

## Overview

This room introduces the fundamentals of how computers encode and represent characters digitally. It explains how text is converted into binary data and how different encoding standards allow computers to store, process, and exchange information.

The room covers essential concepts including ASCII, Unicode, and UTF encodings, helping to understand how characters from different languages are represented inside computer systems.

## Objectives

* Understand how computers represent characters as digital data.
* Learn the basics of ASCII character encoding.
* Explore Unicode and its purpose in supporting multiple languages.
* Understand UTF-8, UTF-16, and UTF-32 encoding formats.
* Build a foundation in data representation and encoding concepts.

## Skills Learned

* ASCII encoding fundamentals
* Unicode character representation
* UTF encoding formats
* Understanding character-to-binary conversion
* Digital text storage concepts

## Tools Used

## Key Takeaways

* Computers store text as numerical values that are converted into binary data.
* ASCII is an early character encoding standard used to represent basic characters.
* Unicode provides a universal system for representing characters from different languages and symbols.
* UTF formats define how Unicode characters are stored using different byte lengths.
* Understanding character encoding is important in programming, networking, file analysis, and cybersecurity.

# JavaScript: Simple Demo

## Overview

This room introduces the fundamentals of JavaScript programming and demonstrates how simple JavaScript programs work. It covers basic programming concepts such as variables, data types, user input, and displaying output.

The room provides a practical introduction to writing and understanding JavaScript code, helping build a foundation for web development, automation, and cybersecurity scripting.

## Objectives

* Learn how to handle user input and display output.
* Build confidence in reading and writing simple JavaScript programs.

# Putting It All Together

## Overview

This room brings together the core concepts involved in how modern websites and web applications operate.

It explains how technologies such as **DNS, web servers, load balancers, CDNs, databases, and Web Application Firewalls (WAFs)** work together to deliver websites efficiently, reliably, and securely.

## Objectives

* Understand how different web technologies work together.
* Learn the role of load balancers.
* Understand how Content Delivery Networks (CDNs) improve performance.
* Learn how web servers process client requests.
* Understand the role of databases in web applications.
* Learn how Web Application Firewalls help protect websites.
* Understand the complete journey of a web request.

## Key Takeaways

* DNS helps translate domain names into IP addresses so clients can locate web services.
* Web servers receive HTTP requests and return the requested web content.
* Load balancers distribute incoming traffic between multiple servers to improve performance and availability.
* Load balancers can use techniques such as **round-robin** and **weighted routing** to distribute requests.
* Health checks help load balancers determine whether servers are available to receive traffic.
* **Content Delivery Networks (CDNs)** store copies of static content on geographically distributed servers so users can receive content from a nearby location.
* Databases store and manage information used by web applications.
* Common database technologies include **MySQL, Microsoft SQL Server, PostgreSQL, and MongoDB**.
* A **Web Application Firewall (WAF)** analyzes web traffic and helps block potentially malicious requests before they reach the web application.
* Modern websites depend on multiple technologies working together to provide performance, availability, and security.

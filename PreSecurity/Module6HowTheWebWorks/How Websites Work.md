# How Websites Work

## Overview

This room introduces the basic technologies that work together to build and display websites.

It explains the roles of **HTML, CSS, and JavaScript**, how browsers process website content, and how client-side code interacts with users. It also introduces basic web security concepts such as sensitive data exposure and HTML injection.

## Objectives

* Understand how websites are built and displayed.
* Learn the roles of HTML, CSS, and JavaScript.
* Understand how browsers interpret web content.
* Learn the basics of HTML elements and attributes.
* Understand how JavaScript can modify webpage content.
* Explore basic client-side security concepts.
* Understand common risks such as sensitive data exposure and HTML injection.

## Key Takeaways

* Websites are mainly built using **HTML, CSS, and JavaScript**.
* HTML defines the structure and content of a webpage.
* CSS controls the appearance and styling of webpage elements.
* JavaScript adds interactivity and dynamic behavior to websites.
* HTML elements can contain attributes that provide additional information or functionality.
* JavaScript can interact with webpage elements through the **Document Object Model (DOM)**.
* Functions such as `document.getElementById()` can be used to access and modify HTML elements.
* Browser Developer Tools help inspect webpage code, network activity, and client-side behavior.
* Sensitive information should not be exposed directly inside client-side code or page source.
* HTML injection can occur when untrusted user input is inserted into a webpage without proper validation or sanitization.
* Understanding how websites work is important before learning web application security.

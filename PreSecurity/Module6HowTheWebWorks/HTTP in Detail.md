# HTTP in Detail

## Overview

This room introduces the fundamentals of **HTTP (Hypertext Transfer Protocol)** and explains how web browsers and web servers communicate.

It covers HTTP requests and responses, methods, status codes, headers, cookies, and how these components work together when accessing websites and web applications.

## Objectives

* Understand the purpose of HTTP and HTTPS.
* Learn how HTTP requests and responses work.
* Understand the structure of URLs.
* Learn common HTTP methods.
* Understand HTTP status codes.
* Explore HTTP request and response headers.
* Understand how cookies are used in web communication.

## Key Takeaways

* HTTP allows clients and servers to communicate and exchange web content.
* HTTPS provides encrypted communication between the client and server.
* URLs contain components such as the scheme, host, port, path, query string, and fragment.
* Common HTTP methods include **GET, POST, PUT, and DELETE**.
* HTTP status codes indicate the result of a request.
* **2xx** codes indicate success, **3xx** indicate redirection, **4xx** indicate client errors, and **5xx** indicate server errors.
* Common status codes include **200 OK, 201 Created, 301 Moved Permanently, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, and 500 Internal Server Error**.
* HTTP headers provide additional information about requests and responses.
* Request headers can include **Host, User-Agent, Accept-Encoding, Content-Length, and Cookie**.
* Response headers can include **Set-Cookie, Content-Type, Content-Encoding, and Cache-Control**.
* Cookies allow websites to store small pieces of information that can be sent with future requests.

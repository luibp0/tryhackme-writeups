# Windows Basics

## Overview

This room introduces the fundamentals of the Windows operating system and teaches how to navigate the environment, manage files, and use essential system tools.

It covers basic Windows features, file management, system settings, and common tools used for everyday computer operations.

## Objectives

- Understand the basics of the Windows operating system.
- Learn how to navigate the Windows interface.
- Manage files and folders effectively.
- Explore essential Windows system tools.
- Build confidence using the Windows environment.

## Skills Learned

- Windows operating system fundamentals
- File and folder management
- Windows navigation
- Basic system administration concepts
- Understanding Windows tools and utilities

## Tools Used

- TryHackMe Learning Platform
- Windows Environment
- Web Browser

## Key Takeaways

- Windows provides an interface for users to interact with computer hardware and applications.
- Files and folders are organized through the Windows file system.
- Built-in system tools help users manage, configure, and troubleshoot computers.
- Understanding Windows is important for cybersecurity because many organizations rely on Windows systems.
- Knowledge of Windows administration helps security professionals analyze and protect systems.

## Reflection

This room improved my understanding of the Windows operating system and its basic features. Learning how to navigate Windows, manage files, and use system tools provides an important foundation for understanding system administration and cybersecurity concepts.

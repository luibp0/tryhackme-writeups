# 🪟 Windows CLI Basics

## Description

**Windows CLI Basics** introduces the fundamentals of the Windows Command Line Interface (CLI). This room covers essential commands used to navigate the file system, manage files and directories, and retrieve system information through the Command Prompt.

The challenge provides hands-on experience with core Windows command-line operations, building a solid foundation for system administration and cybersecurity tasks.

---

## Objectives

* Understand the Windows Command Line Interface.
* Navigate the Windows file system.
* Create, move, copy, rename, and delete files and folders.
* View system and network information.
* Learn essential Windows CLI commands.

---

## Skills Learned

* Windows Command Prompt (CMD)
* File System Navigation
* File & Directory Management
* System Information Gathering
* Command-Line Operations
* Windows Fundamentals

---

## Tools Used

* Windows Command Prompt (CMD)

## Key Takeaways

* The Windows CLI provides an efficient way to manage files, directories, and system resources.
* Understanding basic command-line operations is an essential skill for cybersecurity professionals.
* System information commands assist with reconnaissance and troubleshooting.
* Mastering the Windows CLI lays the groundwork for more advanced Windows administration and security tasks.

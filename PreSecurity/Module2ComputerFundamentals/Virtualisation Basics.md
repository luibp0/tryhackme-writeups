# Virtualisation Basics

## Overview

This room introduces the fundamentals of virtualisation and explains how modern IT systems use virtual machines to improve efficiency, flexibility, and resource management.

It covers how virtualisation allows multiple isolated environments to run on the same physical hardware and how this technology supports modern computing infrastructure.

## Objectives

- Understand the concept of virtualisation.
- Learn how virtual machines work.
- Explore the benefits of virtualisation in modern IT environments.
- Understand how virtualisation improves efficiency and isolation.

## Skills Learned

- Virtualisation fundamentals
- Virtual machine concepts
- Resource management concepts
- Understanding cloud and modern IT infrastructure
- System isolation principles

## Tools Used

- TryHackMe Learning Platform
- Web Browser

## Key Takeaways

- Virtualisation allows multiple virtual systems to run on a single physical machine.
- Virtual machines provide isolated environments that improve security and flexibility.
- Virtualisation helps organizations reduce costs and use hardware resources more efficiently.
- Many cloud computing services rely on virtualisation technologies.
- Understanding virtualisation is important for learning cloud computing, networking, and cybersecurity.

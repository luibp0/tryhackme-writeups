# Client-Server Basics

## Overview

This room introduces the fundamentals of the Client-Server model and explains how computers communicate with each other over networks.

It covers the relationship between clients and servers, how requests and responses work, and how many modern applications and services are built using this architecture.

## Objectives

- Understand the concept of the Client-Server model.
- Learn the roles of clients and servers.
- Understand how requests and responses work.
- Explore how this model is used in real-world applications.

## Skills Learned

- Client-Server architecture fundamentals
- Network communication basics
- Request and response concepts
- Understanding web and application communication
- Basic networking knowledge

## Tools Used

- TryHackMe Learning Platform
- Web Browser

## Key Takeaways

- A client is a device or application that requests services or resources.
- A server provides services, data, or resources to clients.
- Communication between clients and servers usually follows a request-response model.
- Many technologies, including websites and applications, rely on the Client-Server architecture.
- Understanding this model is essential for learning networking and cybersecurity.

## Reflection

This room helped me understand how devices and applications communicate using the Client-Server model. Learning how requests are sent and responses are received provides an important foundation for understanding networks, web technologies, and cybersecurity concepts.

# Cloud Computing Fundamentals

## Overview

This room introduces the fundamentals of cloud computing and explains how businesses use cloud technologies to improve flexibility, scalability, and efficiency.

It covers how cloud services allow organizations to access computing resources on demand without needing to maintain all physical infrastructure themselves.

## Objectives

- Understand the concept of cloud computing.
- Learn the benefits of using cloud services.
- Explore how businesses use cloud technology.
- Understand the basics of cloud scalability and resource management.

## Skills Learned

- Cloud computing fundamentals
- Cloud service concepts
- Scalability and flexibility concepts
- Understanding modern IT infrastructure
- Cloud technology awareness

## Tools Used

- TryHackMe Learning Platform
- Web Browser

## Key Takeaways

- Cloud computing provides access to computing resources over the internet.
- Organizations can scale resources based on their needs without large hardware investments.
- Cloud services improve flexibility, efficiency, and availability.
- Virtualisation is a key technology behind many cloud platforms.
- Understanding cloud concepts is important for modern cybersecurity and IT careers.

## Reflection

This room helped me understand how cloud computing has changed the way organizations build and manage their technology infrastructure. Learning about scalability, flexibility, and cloud services provided a better foundation for understanding modern systems and cybersecurity challenges.

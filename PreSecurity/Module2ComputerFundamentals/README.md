# Module 2: Computer Fundamentals

## Overview

This module provides a foundation in computer fundamentals and explains how modern computer systems work. It covers the basic components of computers, different types of computing devices, communication models, virtualisation, and cloud computing concepts.

Understanding these fundamentals is essential for building knowledge in networking, operating systems, and cybersecurity.

## Key Takeaways

- Computers consist of different components that work together to process and store information.
- Computing devices exist in many forms, from personal computers to embedded systems.
- The Client-Server model is a foundation for many modern applications and services.
- Virtualisation allows multiple isolated environments to run on the same physical hardware.
- Cloud computing provides scalable and flexible resources for modern organizations.
- Understanding computer fundamentals is essential for advancing into networking, operating systems, and cybersecurity.

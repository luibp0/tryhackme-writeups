# Inside a Computer System

## Overview

This room covers the basic components of a computer system and explains how different hardware parts work together to make a computer function.

It introduces the main components inside a computer, their roles, and how data is processed and stored.

## Objectives

- Understand the main components of a computer system.
- Learn the purpose of the CPU, RAM, storage, and other hardware components.
- Understand how computer components communicate with each other.
- Build a foundation in computer hardware concepts.

## Skills Learned

- Computer hardware fundamentals
- CPU and processing concepts
- Memory and storage concepts
- Understanding computer components
- Basic computer architecture

## Tools Used

- TryHackMe Learning Platform
- Web Browser

## Key Takeaways

- A computer system is made up of multiple components that work together to process, store, and transfer data.
- The CPU performs instructions and handles calculations.
- RAM provides temporary memory for running programs.
- Storage devices keep data permanently.
- Understanding computer hardware is essential for learning operating systems and cybersecurity.

## Reflection

This room helped me understand the basic structure of a computer system and how its internal components work together. Learning hardware fundamentals provides an important foundation for understanding operating systems, networks, and cybersecurity concepts.

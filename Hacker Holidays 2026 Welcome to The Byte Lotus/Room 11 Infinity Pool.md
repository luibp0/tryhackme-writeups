# 🌊 Infinity Pool

## Description

**Infinity Pool** focuses on network discovery and enumeration techniques used to identify hidden systems and services within an environment. The room highlights the importance of thorough reconnaissance, demonstrating how undiscovered hosts and exposed network resources can expand an organization's attack surface.

---

## Objectives

- Perform network reconnaissance.
- Discover hidden hosts and services.
- Enumerate network assets.
- Identify exposed systems.
- Assess potential security risks within the network.

---

## Skills Learned

- Network Enumeration
- Host Discovery
- Service Enumeration
- Network Reconnaissance
- Attack Surface Analysis
- Infrastructure Assessment

---

## Tools Used

- Nmap
- Linux Terminal
- Ping
- Network Scanning Utilities
- Enumeration Techniques

---

## Key Takeaways

- Effective reconnaissance is the foundation of every security assessment.
- Hidden systems may expose unexpected services and increase the attack surface.
- Accurate network enumeration helps identify security weaknesses before attackers do.
- Understanding network topology is essential for both offensive and defensive security.

# 🥐 Overheard at Breakfast

## Description

**Overheard at Breakfast** explores the fundamentals of Open Source Intelligence (OSINT) by demonstrating how seemingly harmless conversations can reveal valuable personal information. The room focuses on collecting, correlating, and analyzing publicly available data to build an accurate profile of an individual.

---

## Objectives

- Analyze information gathered from conversations.
- Identify valuable intelligence from public sources.
- Correlate multiple pieces of information.
- Build a digital profile using OSINT techniques.
- Understand the importance of operational security (OPSEC).

---

## Skills Learned

- Open Source Intelligence (OSINT)
- Information Correlation
- Digital Footprinting
- Profile Building
- Operational Security (OPSEC)
- Intelligence Gathering

---

## Tools Used

- Web Browser
- Search Engines
- Social Media Platforms
- Public Records
- OSINT Methodology

---

## Key Takeaways

- Small pieces of publicly available information can reveal far more than expected.
- Correlating multiple data sources is a fundamental OSINT technique.
- Practicing good OPSEC helps reduce unnecessary exposure online.
- Critical thinking is essential when validating and connecting intelligence.

# 🚪 Room 404

## Description

**Room 404** continues the Hacker Holidays 2026 storyline by shifting the focus from information gathering to web enumeration. Although the room appears to be hidden from the hotel's public interface, an exposed service running on **port 8080** provides an alternative entry point.

The challenge revolves around discovering unlisted resources, exploring hidden directories, and identifying exposed files that reveal additional information about the application's structure.

---

## Objectives

* Discover services running on non-standard ports.
* Enumerate hidden web content.
* Identify exposed files and directories.
* Investigate application structure.
* Collect intelligence for the next stage of the challenge.

---

## Skills Learned

* Web Enumeration
* Directory Brute Forcing
* HTTP Enumeration
* Web Application Reconnaissance
* Hidden Resource Discovery
* Information Disclosure

---

## Tools Used

* Web Browser
* Gobuster
* cURL
* Browser Developer Tools

---

## Key Takeaways

* Valuable attack surfaces are often found on non-standard ports.
* Hidden endpoints and directories can expose sensitive application resources.
* Enumeration is a critical phase of every web security assessment.
* Misconfigured web servers may unintentionally expose internal files that aid further investigation.

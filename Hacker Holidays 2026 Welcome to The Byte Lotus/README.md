# 🎄 Hacker Holidays 2026

## Description

**Hacker Holidays 2026** is a seasonal Capture The Flag (CTF) event by TryHackMe that follows a connected storyline set in the **Byte Lotus Hotel**. Throughout the event, participants solve realistic cybersecurity challenges involving reconnaissance, web security, cloud services, operating systems, and digital investigations.

This repository contains my personal notes, methodologies, screenshots, and write-ups for each room completed during the event.

---

## Objectives

* Develop practical cybersecurity skills.
* Practice CTF methodologies and problem-solving.
* Document techniques and lessons learned.
* Build a structured cybersecurity learning portfolio.

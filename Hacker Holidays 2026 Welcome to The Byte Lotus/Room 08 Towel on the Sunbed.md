# 🏖️ Towel on the Sunbed

## Description

**Towel on the Sunbed** explores common web application logic flaws through a reward-claim scenario. The room demonstrates how weaknesses in server-side validation and business logic can allow users to perform actions multiple times when proper controls are missing.

---

## Objectives

- Analyze the application's reward system.
- Identify weaknesses in business logic.
- Understand how repeated requests can bypass intended restrictions.
- Investigate improper server-side validation.
- Assess the security impact of logic flaws.

---

## Skills Learned

- Business Logic Vulnerabilities
- Web Application Security
- Request Analysis
- Session Management
- Authorization Testing
- Vulnerability Assessment

---

## Tools Used

- Burp Suite
- Web Browser
- Browser Developer Tools
- HTTP Requests

---

## Key Takeaways

- Business logic vulnerabilities can be as critical as technical vulnerabilities.
- Security decisions should always be enforced on the server side.
- Reward and transaction systems require proper validation to prevent abuse.
- Analyzing application workflows is essential for identifying logical flaws.

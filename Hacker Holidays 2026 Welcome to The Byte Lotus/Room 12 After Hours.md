# 🌙 After Hours

## Description

**After Hours** explores network monitoring and threat detection by investigating suspicious activity occurring outside normal operating hours. The room focuses on identifying unauthorized systems, unusual network behavior, and indicators of compromise through traffic analysis and system observation.

---

## Objectives

- Monitor network activity for suspicious behavior.
- Identify unauthorized or unexpected systems.
- Analyze network communications.
- Detect indicators of compromise (IOCs).
- Investigate abnormal activity occurring outside regular operations.

---

## Skills Learned

- Network Monitoring
- Traffic Analysis
- Threat Detection
- Indicator of Compromise (IOC) Analysis
- Network Security
- Incident Investigation

---

## Tools Used

- Wireshark
- Linux Terminal
- Nmap
- TCPDump
- Network Analysis Tools

---

## Key Takeaways

- Unusual activity outside normal business hours may indicate malicious behavior.
- Continuous network monitoring is essential for early threat detection.
- Identifying abnormal communication patterns helps uncover compromised systems.
- Combining reconnaissance and traffic analysis improves incident investigation.

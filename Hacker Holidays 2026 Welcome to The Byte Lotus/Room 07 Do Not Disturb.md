# 🚪 Do Not Disturb

## Description

**Do Not Disturb** explores authentication and access control weaknesses in modern applications. The room demonstrates how misconfigurations, exposed credentials, or improperly managed permissions can grant unauthorized access to sensitive resources, emphasizing the importance of secure identity and session management.

---

## Objectives

- Investigate authentication mechanisms.
- Analyze access control implementation.
- Identify unauthorized access opportunities.
- Understand common authorization flaws.
- Assess the security impact of exposed resources.

---

## Skills Learned

- Authentication Analysis
- Access Control
- Authorization Testing
- Session Management
- Security Assessment
- Web Application Security

---

## Tools Used

- Web Browser
- Burp Suite
- Browser Developer Tools
- Linux Terminal

---

## Key Takeaways

- Authentication alone does not guarantee secure access.
- Proper authorization checks must be enforced on every request.
- Misconfigured permissions can expose sensitive information and functionality.
- Secure session management is essential for protecting user accounts.
